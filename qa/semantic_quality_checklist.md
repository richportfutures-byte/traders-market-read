# Semantic Quality Checklist — Actionable-Judgment Preservation

This checklist governs P11 and later semantic review passes for the Trader's Market-Read Glossary.

## Governing Standard

**Actionable in judgment, non-executional in instruction.**

A chapter may teach what the trader should watch, downgrade, confirm, invalidate, classify, monitor, or label. It may discuss read quality, setup quality, location quality, confirmation requirements, invalidation clarity, thesis state, evidence hierarchy, expression quality, and operator posture.

A chapter must not prescribe exact entries, exits, stops, targets, position sizing, adds, reductions, broker actions, order actions, account behavior, fills, or P&L behavior.

## Pass Criteria

For each concept, confirm:

1. The concept teaches the market-read lesson, not merely a sterile definition.
2. Practical Implications explain how the read changes judgment.
3. The chapter says what strengthens, weakens, confirms, or invalidates the read.
4. The chapter names what the trader should watch next when useful.
5. The chapter distinguishes context from permission.
6. The chapter distinguishes thesis validity from setup quality.
7. The chapter distinguishes setup quality from execution permission.
8. The chapter preserves trader-native language when accurate.
9. Participant-flow language is not incorrectly flagged as operator instruction.
10. No entry, exit, stop, target, sizing, add, reduction, broker, order, account, fill, or P&L instruction appears.

## Reclassification Map

When older language is too executional, preserve the trader lesson by translating it as follows:

| Restricted wording type | Reclassify as |
|---|---|
| trade / enter / buy / sell / short | read-quality, setup-quality, or expression-quality implication |
| fade / join as command | rejection, repair, continuation, or sponsorship thesis language |
| size up / size down | confidence, setup quality, conviction, or evidence downgrade language |
| stop placement / move stop | semantic invalidation or failure-condition language |
| target / take partials | objective quality, nearby obstacle, continuation weakening, or path-quality language |
| exit / hold / add | thesis-state, degradation, invalidation, or active-trade-state descriptive language only |

## Negative-Space Review Questions

Ask these during Chapters 5-12 review:

- What would an experienced futures trader know to watch here that is not stated?
- Did safety wording remove the practical trader lesson?
- Does the concept explain what changes when the read strengthens or weakens?
- Does it explain when the read remains context-only?
- Does it explain why the setup might have no clean expression?
- Does it preserve pressure, fuel, sponsorship, exhaustion, trap risk, forced flow, late location, stale thesis, and execution-environment degradation where relevant?

## Red Flags

- The prose says only "not a trade signal" without teaching the usable market-read implication.
- Practical Implications are generic, passive, or compliance-like.
- The chapter avoids saying what to watch next.
- The chapter avoids describing setup or thesis consequences.
- The chapter deletes trader-native concepts because they sound active.
- The chapter converts a useful read into an execution command.
- The chapter treats a label as broker/order behavior.
